# 拍摄计划视觉资料库

为两个拍摄计划收集的视觉与理论材料：

1. **拍龙**——把龙当作天空中的**目击者材料**，而不是神话角色或特效生物。
2. **拍影子**——把影子当作**柏拉图洞穴喻**的光学装置，而不是气氛滤镜。

仓库里这是一份可继续增补的研究档案。浏览用的交互页在对话里的 Canvas；条目正文、出处和公版图在本目录。

## 怎么用

先读 [`00-framework.md`](00-framework.md)，确认两条计划差在观看方向，而不是差在道具。  
再按需要进入：

| 文件 | 内容 |
| --- | --- |
| [`00-framework.md`](00-framework.md) | 两条计划的观看制度、要避开的拍法、交汇点 |
| [`01-dragon-sky.md`](01-dragon-sky.md) | 龙 / 天空 / 目击：绘画、单页画、云图、当代影像 |
| [`02-shadow-cave.md`](02-shadow-cave.md) | 影子 / 洞穴 / 投影：版画、装置、电影、理论 |
| [`03-hinges.md`](03-hinges.md) | 同时咬住两边的作品（烛龙、《不散》、肖维洞窟、3D） |
| [`catalog.json`](catalog.json) | 机读目录，可筛 `plan` / `medium` / `use` |

| [`images/`](images/) | 公版对照图；当代作品只给链接，见 [`images/CREDITS.md`](images/CREDITS.md) |

每条材料尽量包含四件事：**作品是什么、和哪条计划有关、为什么值得拍、去哪里看原件**。

## 拍摄时优先看的十条

龙 / 天空：

1. 陈容《九龙图卷》（云气里的显现，不是标本）
2. Hans Glaser，1561 纽伦堡天象单页画（集体目击文书）
3. 1577 大彗星木刻（画面中有正在画的目击者）
4. 康斯太勃尔云图、弗里德里希《海边的修士》（天空作为对象）
5. 邱黯雄《新山海经》（用古代目击系统看当代天空）

影子 / 洞穴：

6. Jan Saenredam《柏拉图之洞》（洞穴的施工图）
7. 徐冰《背后的故事》（正面是画，背面是材料）
8. Anthony McCall《描述圆锥的线》（光束本身可走入）
9. 威廉·肯特里奇 *In Praise of Shadows*、卡拉·沃克剪影
10. 杉本博司 *Theaters*、蔡明亮《不散》、毕赣《地球最后的夜晚》

两条计划的共用枢纽见烛龙、肖维洞窟和《不散》。
