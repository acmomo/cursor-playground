# 拍摄框架：向上看的目击，对着墙的囚徒

两条计划不是两个题材，而是两种**观看制度**。

| | 计划一：拍龙 | 计划二：拍影子 |
| --- | --- | --- |
| 观看方向 | 向上，对着天空 | 向前，对着洞壁 / 银幕 |
| 观者位置 | 目击者。身体在户外，证据不稳定 | 囚徒。身体被固定，影像被投射 |
| 材料性质 | 目击材料：单页画、云、录像带、手机、传闻 | 光学材料：火、剪影、投影、装置、电影院 |
| 真假问题 | “我看见了，但没法证明” | “我看见了，但那只是影子” |
| 龙 / 影 | 龙作为天空中的事件，而不是角色 | 影子作为洞穴里的事件，而不是道具 |
| 要避免的拍法 | 好莱坞巨龙、圣乔治屠龙叙事、特效生物 | 课堂插图式“洞穴寓言重演”、演员戴镣铐看墙 |

两者共享同一句拍摄问题：**影像怎样成为证据，又怎样暴露自己只是投影。**

## 计划一：龙作为天空目击者材料

这里的“龙”不是叙事里的怪兽，而是一种**被看见但无法被占有**的天空现象。中国的龙本来就住在云雨里：陈容《九龙图》里的龙是云气、水涡和墨点，不是标本。欧洲近代单页画把彗星、日晕、空中交战画成“可怕而奇妙的天象”，旁边还常画一个正在速写的目击者——这已经是纪录片的雏形。

对拍摄有用的传统因此是：

1. **云即龙**：龙从云里露出一截，又隐回去。拍的是显现与消失，不是完整形体。
2. **目击文书**：木刻单页、年鉴、地方志、UFO 录像、手机竖屏。画质差、构图歪、时间码在，才像证据。
3. **天空作为媒介**：康斯太勃尔云图、弗里德里希《海边的修士》、詹姆斯·特瑞尔的天空空间。天空本身就是被拍摄的对象。
4. **非西方的“看见怪物”**：邱黯雄《新山海经》用《山海经》的眼睛看坦克和 UFO——目击系统比科学分类更古老。

关键文献节点：

- 《盎格鲁-撒克逊编年史》793 年：“fiery dragons were seen flying in the air”
- 1547 年泰晤士河上的 *draco volans*，被 William Fulke 解释为云与烟
- 1561 年纽伦堡天象单页画（Hans Glaser）
- 1577 年大彗星布拉格目击木刻（画面中有正在画的人）
- 1873 年得克萨斯 Bonham 云中巨蛇新闻
- 陈容《九龙图》自题：世人望雨，我画出九龙

## 计划二：影子作为柏拉图洞穴喻

柏拉图《理想国》卷七的装置其实非常具体：囚徒面壁；身后是火；火与囚徒之间有一道矮墙；墙后有人举着器物走过；洞壁上出现影子。这几乎已经是电影院的施工图。让-路易·鲍德里（Jean-Louis Baudry）后来把洞穴直接写成电影放映装置理论：不动的观众、被投射的光、把影像当成世界。

对拍摄有用的传统因此是：

1. **把装置拍出来**：不要只拍墙上的影子，也拍火、墙、举器物的手、投影机、烟雾。安东尼·麦考尔《描述圆锥的线》让观众走进光束。
2. **正面是画，背面是垃圾**：徐冰《背后的故事》是当代最干净的洞穴作业——观众可以绕到后面，看见幻象的材料。
3. **剪影不是简化，是政治与记忆**：威廉·肯特里奇、卡拉·沃克、皮影戏、wayang kulit。
4. **电影院就是洞穴**：杉本博司把整部电影曝成一块白屏；蔡明亮《不散》让龙的影像落在空座椅上；毕赣让观众戴上 3D 眼镜才进入后半段。

关键文献节点：

- 柏拉图《理想国》514a–517a
- Jan Saenredam《柏拉图之洞》铜版画，1604
- 谷崎润一郎《阴翳礼赞》，1933（颂影，而不是逃出洞穴）
- 鲍德里《基本电影机器的意识形态效果》
- 肯特里奇演讲 *In Praise of Shadows*（直接反驳柏拉图：影子也是认识）
- 徐冰《背后的故事》，2004 起

## 两条计划在哪里交汇

有些材料同时属于两边，适合做共用资料或将来的第三部分：

- **烛龙**：人面蛇身，睁眼为昼、闭眼为夜，口衔火精照亮没有太阳的西北。它既是龙，又是洞穴里的光源。
- **《不散》**：龙的电影在一座将死的电影院里放映。龙是银幕上的影子，电影院是洞穴。
- **赫尔佐格《遗忘之梦的洞穴》**：3D 摄影机进入肖维洞窟，手电扫过三万年前的兽形。洞穴壁画 + 投影 + 目击。
- **阿彼察邦《热室》**：从洞穴 2D 走到现场 4D，柏拉图与残酷剧场合用。
- **毕赣《地球最后的夜晚》**：贵州矿洞、电影院、3D 长镜头。可感而不可得。
